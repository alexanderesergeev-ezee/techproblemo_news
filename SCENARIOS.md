# Решения и основания

Проектные решения от 14.09.2026. Не являются результатом нагрузочного теста.

| ID | Решение | Причина | Когда пересмотреть |
|---|---|---|---|
| ADR-01 | Отдельный private repo | Изоляция продукта и его контекста | Общий код появился у нескольких зрелых продуктов |
| ADR-02 | Codex Web + GitHub | У владельца уже есть Pro и работающая связка | Появилась конкретная необходимость локального устройства/IDE |
| ADR-03 | Кандидат — существующий Ellery | Не покупать инфраструктуру до проверки гипотезы | Недостаток ресурсов, конфликты или требования изоляции |
| ADR-04 | Один Python-worker | Один пользователь, небольшая нагрузка | Измеренная необходимость параллельного масштабирования |
| ADR-05 | SQLite, не S3 и не отдельный PostgreSQL | Нужны транзакции и состояния при минимуме компонентов | Несколько пишущих экземпляров или клиентов БД по сети |
| ADR-06 | Сохранённая очередь отправки в БД | Перезапуск не должен терять подготовленные карточки | Сам по себе рост таблицы не требует брокера |
| ADR-07 | UNKNOWN без слепого retry | Внешнюю отправку нельзя атомарно объединить с локальной фиксацией | Владелец явно предпочёл вероятные дубли ручной сверке |
| ADR-08 | Score, а не «вероятность» | Число из LLM не подкреплено калибровкой | Проведена проверка вероятностной калибровки |
| ADR-09 | Один внешний LLM-провайдер | Меньше интеграций; не нужна локальная модель | Реально измеренная потребность в fallback/экономии |
| ADR-10 | Частная доставка, не публичная редакция | Сначала проверить качество отбора | Есть стабильная редакционная оценка и права на публикацию |
| ADR-11 | Допуск источников до обработки | Доступность контента не означает разрешение на сбор и AI | Условия/разрешения изменились; нужен новый обзор |
| ADR-12 | Спецификация + тесты обновляются с кодом | Репозиторий должен сохранять контекст между задачами | Этот принцип сохраняется; меняется детализация |

Лёгкий SDD здесь — способ работы: требование → пример/тест → код → проверка → актуальные документы. Установка отдельного SDD-фреймворка не требуется.
