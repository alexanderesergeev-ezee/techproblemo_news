# techproblemo_news — стартовый пакет

Версия документов: 0.1-draft · 14 сентября 2026 года.

**Это спецификация и задания на разработку, а не готовое приложение.** Репозиторий ещё не создан этим пакетом, приложение не написано, сервер не проверен, реальные источники не подключены. Примеры данных синтетические. Предлагаемые решения требуют приёмки владельцем продукта.

## Продукт
Личный радар технологических происшествий: разрешённые источники → сохранение новых материалов → LLM-классификация → карточки релевантных материалов в личном диалоге с Telegram-ботом. Публичная публикация — последующая версия.

## Как использовать
1. Создать отдельный приватный GitHub-репозиторий `techproblemo_news` с начальным README.
2. Распаковать архив и загрузить **содержимое** этой папки в корень репозитория. Не загружать только ZIP: Codex должен видеть обычные файлы.
3. Разрешить существующему Codex Web доступ к новому репозиторию; создать окружение и выбрать нужную ветку.
4. Поручить Codex только TASK-001 из `tasks/CODEX_TASKS.md`. Начать с проверки согласованности документов и небольшого offline-прохода.
5. Принимать последовательные pull request. Проверять diff и результаты тестов; только затем сливать в main.

## Не делать на старте
Не покупать новый сервер без проверки существующего. Не добавлять Kubernetes, Kafka, Redis, отдельный PostgreSQL, RAG, векторную базу, S3 как рабочую базу, веб-интерфейс или агентную оркестрацию. Не отдавать Codex production-секреты и автоматический доступ к развёртыванию.

Это ограничения первой версии, а не утверждение, что перечисленные инструменты плохи.
