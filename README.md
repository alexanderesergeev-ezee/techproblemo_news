# techproblemo_news

Минимальный offline-проход личного радара технологических происшествий. TASK-001 работает
только с синтетическим JSONL, mock-классификатором, локальной SQLite и файловым получателем.
Сетевых источников, LLM API, Telegram API и развёртывания в этой версии нет.

## Установка (Python 3.12)

```bash
./scripts/codex_setup.sh
source .venv/bin/activate
```

Скрипт создаёт `.venv` и устанавливает зафиксированные зависимости из `requirements.lock`.
Секреты и доступ к рабочим API ему не нужны.

## Offline-запуск

```bash
python -m techproblemo_news run-once --offline
```

По умолчанию вход читается из `evals/synthetic_cases.jsonl`, база создаётся в
`data/offline.sqlite3`, а отправленные карточки дописываются в `data/deliveries.jsonl`.
Пути можно переопределить аргументами `--input`, `--database` и `--output`.

## Проверки

```bash
python -m pytest
python -m ruff check .
```

Синтетика проверяет механику, но не качество реальной модели. Граница отбора строгая:
`relevance_score > 0.70`; недостаточный контекст и невалидный результат не доставляются.

## Ограничения

Это один локальный Python-сервис и одна SQLite. Реальные источники могут появиться только после
проверки доступа и прав. Live LLM и личная Telegram-доставка относятся к следующим задачам.
Публичная публикация не входит в версию 0.1.
